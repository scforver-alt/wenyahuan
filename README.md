# 读懂温雅欢 · 朋友养成系

一个纯前端、零依赖的 100 天文字养成游戏。打开 `index.html` 即可玩，无需构建、无需后端。

**在线试玩：** https://scforver-alt.github.io/wenyahuan/

## 玩法

- **开局摸底问答**：8 道关于她的题，答对越多初始面板越高（爱意单独封顶 45）
- **100 天循环**：每天 6 个随机突发事件，覆盖正向分享 / 敏感试探 / 炸毛冲突 / 深夜 emo / 中性日常 / 高危雷区
- **五项公开属性**：心理压力（反向，越低越好）、情绪值、心情值、信任值、爱意
- **四项隐藏数值**：记忆印记、脆弱阈值、占有倾向、自我接纳，只在触发时提示
- **长线剧情**：偏爱试炼线、情绪破防线、心扉敞开线、倦怠疏远线、双向治愈线，外加 6 条支线与 4 个极限抉择
- **7 种结局**：True / Good / Normal / 两种 Bad / 两种隐藏结局

## 技术

单文件 HTML，内联 CSS 与 JS。唯一的外部资源是 Google Fonts。
进度通过 `localStorage` 存在本机浏览器里，不上传任何数据，也不含任何密钥或后端调用。

爱意上涨时触发满屏爱心、选择伤到她时触发落泪特效，均由 Web Animations API 逐颗随机生成，每次形态都不相同。
